# NFW - Workout Hydration Tracker

A simple Flutter application designed to help users stay hydrated during their workout sessions.

## Features

-   **Workout Intensity:** Users can select their workout intensity ('Normal' or 'Heavy') to receive personalized hydration reminders.
-   **Countdown Timer:** The app uses a countdown timer to notify users when it's time to drink water.
-   **Customizable Notifications:** Notifications are scheduled at random intervals based on the selected workout intensity:
    -   **Normal:** Every 10-15 minutes.
    -   **Heavy:** Every 15-20 minutes.
-   **Dark Theme:** A sleek, dark user interface for a focused workout experience.
-   **Persistent Settings:** The user's selected workout intensity is saved locally for convenience.

## Getting Started

This project is a Flutter application. To get started, you will need to have Flutter installed. For help getting started with Flutter development, view the [online documentation](https://docs.flutter.dev/).

1.  Clone the repository.
2.  Run `flutter pub get` to install dependencies.
3.  Run `flutter run` to start the application.
